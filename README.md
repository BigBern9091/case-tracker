# The Docket

A small toolkit for a criminal defense practice (Caddo · Cleveland · Oklahoma County). Each tool is a single self-contained HTML file — no build step, no server.

| File | What it is |
|---|---|
| [`index.html`](index.html) | Launch page linking to each tool |
| [`case-tracker.html`](case-tracker.html) | Case Tracker — docket rail, deadlines (with Google Calendar links), grounds & motions, court minute intake, sentencing exposure, OSCN docket links |
| [`story-desk.html`](story-desk.html) | The Story Desk — theory-of-the-case narrative builder: acts, beats with sources, voice memos, people, issues |

Data entered in the tools is saved in the browser's `localStorage` on the device you use.

> **Confidentiality:** this repository is public and served on GitHub Pages. Anything committed here — including seeded case data — is readable by anyone.
